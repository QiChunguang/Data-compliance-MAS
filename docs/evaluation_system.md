# Evaluation System

ReguThink 的评价体系用于检查报告是否清晰、可信、边界明确。

| 维度 | 示例检查 |
| --- | --- |
| 场景识别 | 是否识别数据交易、数据流通、委托处理、数据出境等场景 |
| 法律依据覆盖 | 是否覆盖与场景相关的主要依据类型 |
| 证据一致性 | 结论是否能回到材料、问答或检索证据 |
| 引用准确性 | 引用是否支持对应结论，是否存在过度引用 |
| 风险识别 | 是否覆盖授权、最小必要、敏感信息、再识别、出境等风险 |
| 结论边界 | 是否避免把辅助分析写成正式法律意见 |
| 报告可读性 | 结构、标题、摘要和建议是否适合业务复核 |
| 人工复核提示 | 是否标记高风险或证据不足位置 |

## Quality Gate

公开展示版强调“评价意识”和“质量控制思路”，不公开私有评分文件、内部阈值或真实运行评分明细。
