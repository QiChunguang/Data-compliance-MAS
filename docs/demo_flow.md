# Demo Flow

1. 打开首页。
2. 上传一份虚构业务材料，例如合作方市场趋势分析项目。
3. 发起合规问题：该数据提供方案是否存在个人信息、再识别或授权风险？
4. 系统自动审查并展示多智能体处理过程。
5. 生成报告草稿。
6. 查看证据引用、风险说明和知识图谱关系。
7. 通过人工复核 Gate 确认需要人工判断的结论。
8. 下载或复制报告。

## Demo Script

建议演示顺序控制在 3 到 5 分钟：

- 30 秒说明项目目标和问题场景。
- 60 秒展示上传材料和对话式审查。
- 60 秒展示风险识别、证据绑定和图谱视图。
- 60 秒展示报告结构和人工复核边界。
