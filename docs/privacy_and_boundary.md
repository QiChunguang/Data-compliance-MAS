# Privacy And Public Boundary

本仓库是 ReguThink / Data-compliance-MAS 的脱敏展示版本。

## Not Included

- 完整法规知识库
- 原始清洗文本库
- 向量数据库或索引
- 图数据库数据
- 真实用户上传材料
- 真实业务材料
- 真实运行日志
- API key、访问令牌、Cookie、数据库密码
- 本地缓存、构建产物、运行产物
- 私有评分文件或不可公开评分细则

## Included

- 前后端展示原型代码
- 脱敏产品说明
- 虚构示例材料和报告
- 公开可读的架构与工作流文档
- 扫描脚本和本地演示说明

## Legal Boundary

本项目为研究/原型展示，不构成正式法律意见。报告示例仅用于说明产品形态和工程设计。
