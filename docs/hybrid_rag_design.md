# Hybrid RAG Design

Hybrid RAG 的目标是让合规报告能够回到可检查的依据，而不是仅依赖模型记忆。

## Retrieval Layers

- 关键词检索：用于稳定命中法规名称、主题词、处理活动和风险词。
- 语义检索：用于召回表达不同但含义接近的依据片段。
- 图谱关系：用于连接法规主题、处理活动、风险类型、证据片段和报告结论。

## Evidence Binding

报告生成前，系统应形成证据绑定表：

- 哪个业务事实来自上传材料或用户确认。
- 哪个风险由哪个事实触发。
- 哪个依据支撑哪个风险判断。
- 哪些结论需要人工复核。

## Public Boundary

本仓库不公开完整法规知识库、向量索引、图数据库、清洗文本库或真实检索日志。示例仅展示数据形状和产品链路。
