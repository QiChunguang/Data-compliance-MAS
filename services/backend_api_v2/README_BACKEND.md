# ReguThink Backend API v2

This is the sanitized showcase backend for the ReguThink demo repository.

## Run

```powershell
cd services\backend_api_v2
python -m uvicorn app.main:app --host 127.0.0.1 --port 8012
```

## Boundary

The public repository does not include private knowledge bases, vector stores, graph database data, real uploaded materials, secrets, or private runtime artifacts.
